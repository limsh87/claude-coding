# TCD v3 · 전략 7 — XCB (eXport Constraint Break)

관세청 통관 4센서를 코어로 한 「제약 붕괴」 탐지. **파일 하나로 완결된다.**

```
strategies/tcd_v3_07_xcb.py     한 셀 실행 · Colab / JupyterLab 양방향
```

Colab이든 JupyterLab이든 이 파일 전체를 한 셀에 붙여넣거나 `python tcd_v3_07_xcb.py` 로
실행하면 **백테스트 → 성과검증 → 강건성검사 R0~R10 → 해석표 → 진단카드**까지 전부 로그에 나온다.
구간 2016-08-01 ~ 2026-07-31.

## 1. 이 전략이 재는 것

수출단가(USD/kg)는 한국 공개 데이터 중 **유일한 순수 가격결정력 측정치**다. GPM은 판가와 원가가
섞여 원재료가 내려도 좋아지지만, 단가는 판매가격 그 자체라 원가 노이즈가 0이다.
그리고 통관은 **금액과 중량을 동시에** 준다 — 수요곡선 위반을 직접 관측할 수 있는 유일한 구조다.

```
log(단가) = α + β·log(물량) + γ·log(투입원가) + ε
정상 기업은 β<0.  많이 팔려면 깎아야 한다.
ε 이 지속적으로 양(+) = 물량이 늘었는데 안 깎았다 = 제약선이 이동했다.
```

**정책 오염 방어가 산식에 내장되어 있다.** 수출바우처·관세환급·무역보험·FTA는 전부 비용이나
리스크를 낮춰 **저가 수주 여력**을 만든다. 따라서:

```
정책 효과   → 물량↑ + 단가↓      (보조받은 만큼 깎을 수 있다)
진짜 제품력 → 물량↑ + 단가유지   (깎지 않아도 팔린다)
```

`TP_X1 = clip(물량↑) × clip(단가유지)` 는 별도 패치가 아니라 **정의 자체가 방어**다.

## 4. ★ KRX 없이도 완전히 동작한다

KRX 마켓플레이스는 2025-12부터 로그인이 필수가 됐고 계정 차단이 흔하다.
**이 전략에서 KRX가 반드시 필요한 곳은 하나도 없다.** 그것을 희망이 아니라 **실측**으로 보장한다.

`KRX_ENABLED = False` 로 두면 자격증명을 환경변수에 **주입조차 하지 않아** pykrx가
import 시점에 실패 로그인을 반복하지 않는다(계정 상태를 더 악화시키지 않는다).

| 항목 | 소스 | KRX 의존 |
|---|---|---|
| 종목 마스터(생존+폐지) | FDR 상장목록 + KIND + FDR 상장폐지 | **불필요** |
| 생존자편향 제거 C2 | 폐지목록 + 마지막 거래일 복원 | **불필요** |
| PIT 유니버스 C13 | 상장일·폐지일 + 가격 관측 | **불필요** |
| 가격·거래대금 | FDR → 네이버 → yfinance | **불필요** |
| 시가총액(규모버킷만) | KRX 있으면 정확 / 없으면 상장주식수 역산 근사 | 약화(감사표 표기) |
| 투자자 수급 d3 | KRX → 네이버 폴백 → 없으면 U에서 제외 | 약화(0 채움 금지) |

실측(KRX 완전 차단 상태): 마스터 **5,398종목** · 폐지 종목 **2,526건** 포함 · 상장일 확보율 **46.8%**.

## 5. 구글드라이브 캐시 — 절대 1원칙

**기존 캐시·인덱스를 훼손하지 않는다.** 약속이 아니라 **구조**로 보장한다.

이 계정에는 서로 다른 워크스페이스가 **7개** 있고, 리포트 원장의 본체는 `tcd_cache` 가 아니라
`QuantCache/common/reports` 에 있다(report_ledger 30.7만행 · analyst_registry 1,860명 · blob_map 500 PDF).
그래서 형식별 어댑터 4종을 두고 **읽기 전용**으로 흡수한다:

| 형식 | 예 |
|---|---|
| `_manifest_*.json` | QuantCache/common, strategies/TCD_ADX |
| `public_index.json` (`kind\|ym`) | ARC_COMMON_LEDGER |
| `index.jsonl` (append-only) | tcd_cache/_shared |
| `done_index.json` (`src:src_id`) | FPU7 워크스페이스 |

- 외부 인덱스는 `open(..., "r")` 로만 연다. 쓰기 모드로 여는 곳이 **없다**.
- 삭제 API 자체가 없다(계약 테스트가 소스 검사로 강제. 예외는 우리가 만든 잠금파일뿐).
- 유일한 쓰기 경로 `foreign_publish_common` 은 ① 새 이름으로만 파일 생성 ② **새 키만 추가**
  ③ 타임스탬프 백업 ④ 원자적 교체 ⑤ **재읽기 검증** ⑥ 실패 시 자동 롤백 — 전부 통과해야 커밋된다.
  하나라도 실패하면 사이드카 파일로 물러난다.
- 공용 `_shared` / 전용 `tcd_v3_xcb` 로 분리 저장 → 다른 전략이 그대로 재사용 가능.

## 6. 구조 — 실패 지점이 어디인지 한눈에

```
[0] 환경·금고 연결 → 외부캐시 흡수 → 계약 자동검정 8건
[1] 합성 스모크          ← 실데이터 쓰기 전에 계산경로를 먼저 증명
[2] CANARY X1~X6 / K1~K12  ← 축 유효성 실측. FAIL 항목에 의존하는 단계는 큐에서 제거
[3] 유니버스 · 가격 · 통관 · DART · 리서치
[4] HS 큐레이션 + 매핑 4중 게이트
[5] L1 센서 → L2 스코어 → L3 백테스트
[6] 성과검증 · 원장 무결성 감사 · 해석표
[7] 강건성 R0~R10
[8] 진단카드 · 감쇠표 · 런타임 · 데이터흐름 지도 · 산출물
```

모든 연산은 `PIPE.stage(...)` 안에서만 돈다. 실패하면 자동으로 출력되는 것:
**스테이지 ID · 계층 · 경과시간 · 직전 입출력 스냅샷 · 한글 진단힌트 · 트레이스백 마지막 12줄.**

## 8. 알려진 한계 — 숨기지 않는다

1. **유니버스가 얇다.** 우측 꼬리 의존이 극단적이다. 상위 1%/5%/10% 종목 제외 시 성과를
   측정해 **리포트 첫 페이지**에 명시한다.
2. **큐레이션이 최대 자유도다.** `hs_universe_preregistered.csv` 로 사전등록하고 이후 실행은
   그 파일을 따른다. 성과를 보고 고치면 그 순간 과적합이다.
3. **HS–KSIC 연계표**는 공개 정본이 없다. 확보 실패 시 내장 씨앗표(章↔KSIC 중분류)로 떨어지며
   CANARY X6 = DEGRADED 로 보고한다. 이때 매핑 게이트 1·2·3의 판정이 그만큼 더 중요해진다.
4. **컨센서스 fwd EPS 시계열은 과거 복원이 불가능**하므로 d1의 E는 후행 12M 이익 대리변수다.
5. **관세청 현행화**로 시점 t의 원공표값은 사후 복원이 불가능하다. 보수적 knowledge_date로
   위험을 흡수하고, 오늘부터 월별 스냅샷을 적재해 다음 실행부터 X5를 실측한다.
6. 두 리서치 사이트 모두 `robots.txt` 가 `Disallow: /` 다. 사용자의 명시적 지시에 따라
   보수적 속도로 수집하며 그 사실을 로그에 남긴다.
