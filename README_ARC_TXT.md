# ARC-TXT v2.0 — 애널리스트 텍스트톤 변화 × DART 3층 교차확증

한국 하위 1000 소형주 대상 퀀트 시스템. 명세서 ARC-TXT v2.0 구현체.
백테스트 구간 **2016-08 ~ 2026-07 (10년)**, **분기 리밸런싱**.

> **두 축이 서로 다른 마찰을 관측한다.**
> **축 A** — 애널리스트는 정성적 판단을 서술문에 먼저 반영하고 목표주가·투자의견은 지연 갱신한다.
> 저커버리지 소형주일수록 그 텍스트를 읽는 투자자가 적다. 지속성의 근거는 "아무도 모른다"가 아니라
> **읽는 비용이 자본화되지 않는 구조**다.
> **축 B** — 기업은 정기보고서를 전기 문서 복붙으로 쓴다. 그래서 **문서를 능동적으로 고쳤다는 사실
> 자체가 신호**다(D1). 여기에 검증된 재무 이상현상(D2)과 완료형 하드팩트(D3)를 얹는다.

## 1. 실행

`strategies/arc_txt_v2.py` **파일 하나로 완결**된다.
Colab / JupyterLab 한 셀에 붙여넣거나 `python arc_txt_v2.py` 로 실행하면 전부 로그로 나온다.

```
[0] 환경·의존성 → 캐시 연결 → 계약 자동검정 A1~A21
[1] 합성데이터 엔드투엔드 스모크   ← 실데이터 쓰기 전에 계산경로를 먼저 증명
[2] 실경로 리허설                  ← 네트워크만 가짜, 수집·정제 함수는 실물 실행
[3] 데이터 수집 (로컬+드라이브 캐시 우선 → 부족분만 신규 → 드라이브 재적재)
[4] Phase 0 게이트 6종             → 어느 축이 살아있는지 확정
[5] 원장 무결성 감사 (보고서 ↔ 애널리스트 ↔ 종목)
[6] U-1000 PIT 유니버스 (상장폐지 포함 · 미래시총 소급 금지)
[7] 축 A(TONE→ΔTONE→직교화) / 축 B(D1·D2·D3·배제) → FINAL_SCORE
[8] 백테스트 → 성과 검증 (비용 전/후 병기)
[9] 어블레이션 11종 → BH-FDR 보정 → 강건성 R1~R11 → 섹터/시총 분해
[10] 해석표 · 진단카드 · 폐기 판정 · 산출물 다운로드 링크
```

| `RUN_MODE` | 동작 | 용도 |
|---|---|---|
| `"SMOKE"` | 합성데이터로 **전 출력물 예행연습**. 네트워크·키 불필요, 30초 | 처음 한 번은 이걸로 |

## 2. 구글드라이브 캐시 — 절대 1원칙

**기존 캐시·인덱스를 훼손하지 않는다.** 약속이 아니라 **구조**로 보장한다:

1. 인덱스의 진실은 **append-only JSONL 저널**이다. 기존 줄을 다시 쓰지 않는다.
2. `index.parquet` 은 저널의 파생물이며 재생성 전 **항상 타임스탬프 백업**. 백업 실패 시 컴팩션 자체를 건너뛴다.
3. 컬럼은 **합집합으로만 확장**. 스키마가 달라도 기존 컬럼을 떨어뜨리지 않는다.
4. blob 은 **내용해시 경로**에 쓰므로 같은 내용은 재기록조차 하지 않는다.
5. 이미 드라이브에 있던 리포트는 **이동·개명 없이 경로만 등록**한다(adopt-by-reference).
6. **삭제 API 자체가 없다.** 손상 파일조차 `.corrupt` 로 격리만 한다.

```
{캐시루트}/
├── _shared/          ← 공용 인덱스: TCD v2 등 다른 전략도 그대로 재사용
│   ├── index/{index.jsonl(원천), index.parquet(파생), _backup/}
│   ├── blob/{research/report_pdf/…, dart_doc/raw/…}
│   └── table/{krx_ohlcv_daily, krx_marketcap_pit, dart_fnltt_raw, dart_shares,
│              dart_audit, dart_disclosures, dart_doc_norm_<연도>,
│              research_report_master, research_report_text_<연도>,
│              analyst_master, report_analyst_link, …}
└── arc_txt_v2/       ← 전용 인덱스: 이 전략 고유
    └── table/{l1_features_*, l2_scores_*, backtest_returns_*}, reports/
```

**캐시 탐색은 로컬과 드라이브 양쪽에서 한다** (`CACHE_SEARCH_DIRS`).
Colab 마운트 · 드라이브 동기화 폴더 · `D:/` 로컬 경로를 모두 훑는다.
**신규 수집분은 전부 드라이브에 저장**되고 다음 실행에서 증분 재사용된다.

## 3. 편향 제거

| 편향 | 대응 | 강제 장치 |
|---|---|---|
| **미래누수** | 모든 테이블은 `pit_frame()` 을 통과해야 `PITStore` 에 등록된다(PIT 컬럼 없으면 `KeyError`). 조회는 `PIT.get` / `PIT.asof_join` 뿐. DART 는 **접수일 + 1거래일**, 리포트는 **발간일 + 1거래일**, 가격은 **t−1 종가까지** | A1 · A15 · **A19** |
| **생존자편향** | 상장폐지 종목을 PIT 스냅샷에 포함. 정리매매가 없으면 **−100%**. `asof_join` 이 결합키 결측 행을 버리지 않는다 | A2 |
| **미래 시총 소급** | U-1000 랭크는 **그 시점에 관측된 시총**으로만 매긴다. 다른 시점 시총을 넣으면 유니버스가 비도록 설계 | **A3** |
| **가짜 텍스트 변화** | 숫자·날짜·기수·사명을 마스킹. 숫자·날짜·사명만 바뀐 문서의 자카드가 **0.98 이상**이어야 하고, 실제 서술이 바뀐 문서는 유의하게 낮아야 한다 | **A5** |
| **서식 개정 공통충격** | 유사도를 (기간 × 섹션) 횡단면에서 z-score → 공통충격이 평균에 흡수 | §6.1.5 |
| **IDF 누수** | 전체 기간 문서로 IDF 를 만들면 미래 단어 빈도가 과거에 들어간다 → 확장(expanding) IDF | §6.1.4 |
| **TONE 누수** | 확장윈도우 재학습. 시점 t 예측에는 t 이전 데이터로만 학습된 모델 | §5.1 |
| **팩터 재포장** | ΔTONE 을 컨센 수정·목표주가 수정·의견변경·모멘텀·사이즈·유동성·섹터에 회귀한 **잔차**를 신호로 | **A12** (상관 실제 제거 검증) |
| **과적합** | 가중치 전부 사전등록(0.40/0.40/0.20, 0.5/0.5). 최적화 루틴 부재를 소스 검사로 강제 | **A13** |
| **다중검정** | 어블레이션 11개를 하나의 패밀리로 묶어 BH-FDR (q=0.10) | §8.3 |

## 4. Phase 0 게이트 — 실패해도 전략을 폐기하지 않는다

```
GATE_1 median(pair_count) ≥ 150   GATE_4 dart_pair_rate  ≥ 0.85
GATE_2 min(pair_count)    ≥ 80    GATE_5 dart_parse_rate ≥ 0.80
GATE_3 text_extract_rate  ≥ 0.70  GATE_6 fs_cov          ≥ 0.90
```

- GATE_1/2/3 실패 → **축 A 비활성화**, `DART-ONLY 폴백` 으로 명시 보고 (v1.0 과 달리 축 B 가 독립 작동)
- GATE_4/5 실패 → D1 비활성화 + **사유 분해표**(PDF 스캔본 / 서식변경 / 전년동기 부재 / 호출한도)
- GATE_6 실패 → D2 비활성화 + **심각 이슈** 배너 (D2 는 D1 보다 대체 불가)

★ 게이트는 **실제로** 축을 끈다. `PIPE.stage(skip_if=)` 는 표시만 하고 본문을 막지 못하므로
오케스트레이터가 명시 분기로 처리하며, 그 사실을 **A20** 이 검사한다.

## 5. 신호 구조

```
FINAL_SCORE = 0.5 · z(ΔTONE_resid) + 0.5 · z(DART_SCORE)
DART_SCORE  = 0.40·D1 + 0.40·D2 + 0.20·D3        (사전등록. 튜닝 금지)

편입 조건: 배제플래그 = 0  AND  FINAL_SCORE 상위 랭크
보유 20~40종목 · 동일가중(기준) + 역변동성(병행) · 분기 리밸런싱
```

**탈락시키지 않기 규칙 세 가지** (각각 계약검정으로 고정):
- 축 A 결측(리포트 없음) → 중립 0 으로 두고 DART_SCORE 만으로 평가 — **A10**
- D1 결측 → D1 가중치를 D2·D3 에 **비례 재배분** — **A11**
- `ΔNONFIN = 0` 인 종목도 편입 가능 (v1.0 하드게이트 폐기) — **A9**

**단, '정보 없음' 은 '중립 0' 이 아니다** — 축 A 단독 팔에서는 결측을 결측으로 남기고,
두 축이 모두 결측인 행은 편입 대상에서 뺀다 — **A21**

**배제 플래그 8종만이 하드 제외**다 (특수관계자·우발부채·소송·감사의견·최대주주변경·
CB/BW·4분기 연속 영업적자·자본잠식) — **A8**

## 9. 알려진 한계 (숨기지 않는다)

1. **EPS 컨센서스 시계열은 과거 복원이 불가능하다.** 직교화 통제변수 `eps_rev` 는 PIT 실적
   (TTM 순이익/자산) 변화율 대리변수를 쓴다. '컨센서스 수정'이 아니라 '실현 실적 변화'이므로 통제력이 약하다.
2. **관리종목·투자주의환기·거래정지 지정 이력**은 공개 API 로 과거 전 구간 복원이 불가능하다.
   종목 속성(스팩/우선주/리츠)은 정확히 제외하고, 지정 사유(자본잠식·연속적자·감사의견)는
   배제 플래그가, 거래정지는 유동성 하한이 근사한다.
3. **특수관계자·우발부채·소송 금액 판정**은 정규화 이전 원문 재파싱이 선행되어야 해 현재 결측이다.
   결측률을 표로 노출하며, 거짓 제외보다 결측이 낫다는 원칙을 따른다.
4. **Lazy Prices 는 미국 10-K 결과다.** 한국 사업보고서 재현 증거는 확인된 바 없으며,
   이 백테스트의 **검증 대상**이다. 부호가 역전되면 §9.3-5 에 따라 D1 을 '검증 실패'로 처리하고
   F2 를 주 결과로 삼는다 — **부호를 뒤집어 성과를 맞추지 않는다.**
5. **DART 콜드빌드는 일일 호출한도 때문에 며칠 걸린다.** 중단해도 드라이브에 저장되어
   정확히 그 지점부터 이어받는다. 콜드빌드는 4시간 반복예산 밖이다.
6. **형태소 분석기가 없으면** soynlp → 규칙기반으로 폴백한다. D1 은 동작하지만 어미 절단이
   거칠어 유사도 분산이 커진다. 어느 경로가 쓰였는지 로그에 명시된다.
7. **한경컨센서스·네이버금융은 `robots.txt` 가 `Disallow: /`** 다. 사용자의 명시적 지시에 따라
   수집하되 보수적 속도로 제한하고 그 사실을 로그에 남긴다. PDF 원문은 증권사 저작물이므로
   로컬 캐시/분석 용도로만 사용할 것.
