# 2020-06-30 원문 대조 픽스처 (§14)

`reference_20200630.csv` 는 **원문 PDF 표7(p.16)의 30종목**을 담는 검증용 고정 파일이다.

## 이 파일은 지금 비어 있다 — 그리고 그것이 올바른 상태다

원문 PDF가 이 저장소에 없다. 코드가 30종목을 "그럴듯하게" 만들어 채우면 그 순간
검증 픽스처가 아니라 **날조**가 된다(§0-2, §27). 그래서 헤더만 두고 비워 뒀다.

실행하면 `11_reference_20200630_match.csv` 에 `fixture_status=REFERENCE_FIXTURE_EMPTY`
가 기록되고, 해석 문서는 이를 "재현 실패"가 아니라 **"검증 재료 부재"** 로 구분해 적는다.

## 채우는 방법

PDF 16쪽 표7을 보고 아래 컬럼을 채운 뒤 저장하면, 다음 실행부터 자동으로 대조가 수행된다.

| 컬럼 | 의미 | 필수 |
|---|---|---|
| `rank` | 표7에서의 순위 (없으면 비워 둘 것 — 순위상관만 건너뛴다) | 선택 |
| `company_code` | 6자리 종목코드. `005930` 처럼 앞의 0 을 유지할 것 | **필수** |
| `company_name` | 종목명 | 선택 |
| `surprise_probability` | 서프라이즈 확률 | 선택 |
| `fq1_eps_yoy` | FQ1 EPS 증가율(YoY) | 선택 |
| `fy1_eps_yoy` | FY1 EPS 증가율(YoY) | 선택 |
| `smart_gap_fq1` | Smart Gap(FQ1) | 선택 |
| `eps12mf_rev_1m` | 12개월 선행 EPS 1개월 변화율 | 선택 |
| `inst_20d` | 20일 기관 순매수 강도 | 선택 |
| `foreign_20d` | 20일 외국인 순매수 강도 | 선택 |
| `source_page` | 출처 페이지 (16) | 선택 |

단위 주의: 표에 `%` 로 적힌 값은 소수(0.12)와 퍼센트(12) 중 **하나로 통일**해 넣어야
`factor_value_correlations` 가 의미를 갖는다. 상관계수는 단위에 불변이므로 스케일이
달라도 상관 자체는 유효하지만, 값 자체를 비교할 생각이라면 소수로 통일하는 편이 낫다.

## 채운 뒤에 하면 안 되는 일

겹침(overlap)이 낮게 나왔다고 해서 half-life·lookback·윈저라이즈·종목 수를 표7에
맞춰 조정하는 것. 이것이 §14 와 §27 이 가장 명시적으로 금지하는 행위다.
표7은 **학습 대상이 아니라 검증 대상**이다. 불일치는 불일치대로 기록한다.
