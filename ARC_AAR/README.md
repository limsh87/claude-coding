# ARC-AAR — 애널리스트 주의 재배분 (SPEC-C 단독 구현체)

한국 시장 애널리스트의 **현시선호(주의 배분)** 만으로 양방향 신호를 만드는 전략의
10년(2016-08 ~ 2026-07) 백테스트 원셀 실행형 파이프라인입니다.
계약문서(SPEC-C / ARC-AAR)만을 근거로 제로베이스에서 작성되었으며, 저장소의 다른
전략 코드를 참조하지 않습니다.

## 파일

- `arc_aar_run_all.py` — 단일 파일 전체 파이프라인 (수집→정제→패널→통제회귀→
  철회 인과분해→백테스트 12구성→이벤트 스터디→통계 검증→산출물/표 출력)

## 실행

```bash
# Colab: 파일 업로드 후 셀에서
%run arc_aar_run_all.py
# 또는 파일 전체를 셀 하나에 붙여넣고 실행

# JupyterLab(로컬/Windows)
%run arc_aar_run_all.py

# 터미널
python arc_aar_run_all.py
```

- 자격증명(KRX 마켓플레이스 ID/PW, DART API 키)은 **파일 최상단 [S00]** 에서 입력.
  발급처 URL/절차가 주석으로 안내됨. 비워두면 대화형 1회 질의(비대화형이면 스킵 후
  폴백 체인 사용).
- 모드: 환경변수 `ARC_AAR_MODE` = `FULL`(기본) / `SYNTH`(네트워크 없이 전체
  파이프라인 자가검증) / `CANARY`(소스 도달성만 점검).

## 수집 경로 설계 — 왜 이렇게 짰는가

수집 경로는 **요청당 산출량(reports per request)** 으로 결정됩니다. 이 값을 무시하면
어떤 시간 예산으로도 완주할 수 없습니다.

| 경로 | 요청당 산출 | 작성자 | 157개월 소요 | 역할 |
|---|---|---|---|---|
| 한경 컨센서스 리스트 | 최대 80건 | 있음 | 약 4,700요청 ≈ 45분 | **주력** |
| 네이버 리서치 리스트 | 약 30건 | 없음(증권사만) | 약 9,400요청 | 항상 병행 |
| 네이버 상세 페이지 | 1건 | 있음 | 약 31만요청 ≈ 48시간 | 전역 예산제 보조 |
| PDF 본문 | 1건(수 MB) | 있음 | 불가 | 기본 비활성 |

한경이 막히면 계약 §3의 공식 폴백인 `broker × sector`(하우스 단위)로 내려갑니다.
네이버 리스트만으로 증권사는 100% 확보되므로 폴백은 항상 실행 가능합니다.

## 반복 조회 제거

- **증분 수집**: 가격은 캐시의 마지막 날짜 다음날부터만 받아 이어붙입니다. 전체
  히스토리를 다시 받는 일이 없습니다. 이어붙이는 지점에서 45% 이상 점프가 보이면
  수정주가 기준 변경(액면분할 등)으로 판단해 그 종목만 전체 재수집합니다.
- **벌크 증분**: 결손 구간이 짧으면 종목별 호출 대신 '날짜별 전종목' 조회를 씁니다.
  20영업일이면 2,500콜 대신 40콜입니다.
- **실패 기억**: 데이터가 없는 종목(상폐 등)은 쿨다운 기간 재시도하지 않습니다.
- **통합 행렬**: close 매트릭스를 단일 parquet로 캐시해 매 실행 수천 개 파일을
  다시 읽지 않습니다.
- **완료 키**: 가격 완료 레지스트리 키에 종료월을 넣지 않습니다. 넣으면 달이 바뀔
  때마다 전체가 미완료로 뒤집힙니다.

## 멈춘 것처럼 보이지 않게

워치독 스레드가 20초마다 현재 작업·진행률·처리속도·예상 잔여시간을 출력합니다.
403/404는 백오프 재시도 없이 헤더 프로파일을 한 번 바꿔 보고 즉시 포기하며,
카나리에서 차단 판정된 소스는 처음부터 끄고 시작합니다. 레이트리밋은 적응형이라
정상 구간에서는 점점 빨라지고 차단 신호가 오면 즉시 느려집니다.

## 핵심 동작 규약

- **구글드라이브 절대 1원칙**: 신규 수집 데이터는 전부 드라이브에 저장되고
  `공용인덱스(common_index.json)` / `전용인덱스(arc_aar_index.json)` 에 등록됩니다.
  기존 인덱스는 append-only 병합 + 타임스탬프 백업 + 검증 후 원자 교체로 **절대
  파괴되지 않으며**, 파싱 불가 인덱스를 만나면 원본을 건드리지 않고 사이드카로
  전환합니다. 타 전략 레거시 인덱스는 읽기전용으로 재활용합니다.
- **캐시 탐색**: 로컬(홈/D드라이브) + 드라이브 양측을 모두 탐색, 드라이브 부재 시
  pending 큐 적재 후 다음 실행에서 자동 동기화.
- **수집 4시간 타임박스**: 초과 시 수집을 우아하게 멈추고 그때까지의 데이터로
  **INTERIM 백테스트 결과**를 산출(모든 산출물에 표기). 재실행 시 완료분은 스킵하고
  이어서 수집합니다. 계산 단계에는 시간 제한이 없습니다.
- **실시간 쿼터**: DART 등 API 는 고정 예산을 가정하지 않고 서버 응답('020' 등)과
  금일 사용량으로 잔여 호출량을 추적, 소진 시 키 교체/우아한 중단.
- **PIT/생존편향**: KRX 월말 전종목 스냅샷으로 유니버스를 구성해 상장폐지 종목을
  포함(스냅샷 소멸=상폐 추론), 진입은 익영업일 종가, 통제회귀는 확장윈도우
  재귀추정으로 look-ahead 차단.

## 기간과 워밍업

사전등록 백테스트 구간은 **2016-08 ~ 2026-07**(10년)입니다. 신호가 이 구간의 첫
달부터 실제로 산출되려면 베이스라인 룩백 12개월 + 통제회귀 최소창 24개월 + 신호월
1개월 = **37개월의 워밍업**이 필요하므로, 리포트 메타 수집은 2013-07부터 시작합니다.
실행 종료 시 사전등록 구간이 실제로 채워졌는지 검증해, 미달분이 있으면 INTERIM으로
표기하고 `OPEN_QUESTIONS.md`에 절단 사유를 기록합니다.

## 검증 상태

`ARC_AAR_MODE=SYNTH` 는 효과를 미리 심어둔 합성 시장을 만들어 파이프라인이 그것을
되찾아내는지 확인하는 자가검증 모드입니다. 최종 실행 결과:

| 점검 | 결과 |
|---|---|
| H1 (주의 증가 → 양의 수익) | 회수 — Q5−Q1 NW t = 5.79 |
| M-EXIT 플라시보 (귀무여야 함) | 유지 — CAR60 +1.35%, t = 0.93 |
| V-DROP (음이어야 함) | 방향 회수 — CAR60 −0.88%, t = −1.91 |
| H5 그레인저 선행성 | 회수 |
| Phase 0 확보율 | 심어둔 참값(≈77%)을 78~80%로 복원 |
| PBO / DSR / 워크포워드 / 부트스트랩 | 0.36 / 1.00 / OOS Sharpe 1.20 / P(SR≤0)=0.000 |
| 사전등록 10년 구간 | 2016-08 ~ 2026-07 충족 |

자가검증의 한계 두 가지를 명시합니다. **V-DROP은 방향은 맞지만 t=−1.91로 유의수준에
못 미칩니다** — 검출기가 산발적 발간 패턴 위에서 심어둔 이벤트의 약 5배를 잡아내
효과가 희석되기 때문이며, 이는 실데이터에서도 H3 검정이 어려울 수 있다는 신호입니다.
**H-EXIT은 합성 세계에서 10건만 발생해 사실상 검증되지 않았습니다** — 같은 증권사의
2인 이상이 동일 종목을 커버하는 상황이 합성 세계에서 드물게 설계된 탓입니다.
